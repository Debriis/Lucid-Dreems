# Artwork and captures

Active dream rooms use supplied FEVER DREAMS textures and GLB characters,
rendered at 320x180. Native 1280x720 text and UI stay outside that viewport.
All original kit files, credits and license documents remain in fever_dreams/.

Current-*.png files are actual gameplay/cinematic captures from the canonical
four-box story. FP-*.png and earlier preview images are historical references.
No captured image substitutes for a playable dream room. The supplied office
background is used only for the appointment, ending and impossible doorway.
