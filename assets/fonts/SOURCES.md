# Menu and interface fonts

- **Rubik Glitch Regular**: NaN / Rubik project. SIL Open Font License 1.1. Font: https://github.com/google/fonts/blob/main/ofl/rubikglitch/RubikGlitch-Regular.ttf . License: `RubikGlitch-OFL.txt` from https://github.com/google/fonts/blob/main/ofl/rubikglitch/OFL.txt . Used for menu and pause headings.
- **Special Elite Regular**: Astigmatic. Apache License 2.0. Font: https://github.com/google/fonts/blob/main/apache/specialelite/SpecialElite-Regular.ttf . License: `SpecialElite-LICENSE.txt` from https://github.com/google/fonts/blob/main/apache/specialelite/LICENSE.txt . Used for clinical notes, speaker tabs, and hints.
- **DotGothic16 Regular**: Fontworks. SIL Open Font License 1.1. Existing imported copy and license are retained in `assets/replacements_v2/ui/fonts/`. Used for readable dialogue, choices and controls.

The two added font files are unmodified. Their original license files accompany them. Dialogue uses a subtle one-pixel ink shadow instead of changing the source font. Decorative headings use Rubik Glitch; body text remains 26px and receives no distortion shader.
